# SkyReserve
> Group 8 - Darren Chai, Tay Chew Yun, Xena Lim

## Project Overview

**SkyReserve** is a direct European flight booking platform offering non-stop routes between major European hubs and Scandinavian destinations, including:
- **ARN** — Stockholm Arlanda
- **LHR** — London Heathrow
- **CDG** — Paris Charles de Gaulle
- **BER** — Berlin Brandenburg
- **AMS** — Amsterdam Schiphol
- **BCN** — Barcelona El Prat
- **FCO** — Rome Fiumicino
- **LLA** — Luleå Kallax
